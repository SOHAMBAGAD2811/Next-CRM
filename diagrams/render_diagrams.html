Diagram 5: Data Flow Sequence

sequenceDiagram
    participant U as User
    participant F as Frontend (Next.js)
    participant B as Backend (Flask)
    participant V as VADER NLP
    participant S as Scoring Engine
    participant C as Churn Calculator
    participant DB as MySQL

    U->>F: Create Lead / Log Interaction
    F->>B: POST /api/leads or /api/leads/:id/interactions
    B->>DB: Save lead/interaction record
    B->>V: Analyse text sentiment
    V-->>B: Positive / Neutral / Negative
    B->>S: Compute AI score (0-100)
    S-->>B: Score based on stage + value + sentiment + recency
    B->>C: Evaluate churn risk
    C-->>B: is_at_risk: bool, risk_pct: int
    B->>DB: Update lead fields + save score history
    B-->>F: Return updated lead JSON
    F-->>U: Render updated UI
